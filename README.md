# İdiz'in Tezgâhı

Oro Kıtaları evreninde, Haarbova'nın Agreguk pazarında geçen bir dükkân oyunu. Dermançöl ordusundan kaçan Yavşuk İdiz, Uçmakanların pazarında tezgâh açar ve ailesini kurtarmak için 10 milyon nüd biriktirmeye çalışır.

**Oyna:** https://koloboros.github.io/Yavsuk-Tezgah-/

Telefonda dikey oynanmak üzere tasarlandı. Kayıtlar tarayıcının kendi hafızasında tutulur.

## Dosyalar

- `index.html`: Oyunun kendisi, tek dosya. GitHub Pages bunu yayınlar.
- `kaynak/`: Oyunun parçalara ayrılmış kaynak kodu. `sh kaynak/build.sh` komutu bu parçaları birleştirip `index.html` dosyasını yeniden üretir.
